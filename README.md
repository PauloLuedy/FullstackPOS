# Jogo de Apostas

Jogo simples de adivinhação onde você aposta pontos tentando acertar um número de 1 a 10.

## Versões disponíveis

### Versão Terminal
```bash
python jogo_apostas.py
```

### Versão Interface Gráfica (Recomendada)
```bash
python jogo_apostas_gui.py
```

## Como jogar

1. Você começa com 1000 pontos
2. Escolha o valor da aposta
3. Escolha um número de 1 a 10
4. Se acertar, ganha 5x o valor apostado
5. Se errar, perde o valor apostado

## Regras

- Saldo inicial: 1000 pontos
- Multiplicador de ganho: 5x
- Números válidos: 1 a 10
- Chance de ganhar: 15% (50% maior que o normal)
